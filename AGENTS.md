# Работа с DCA800
Общение с владельцем — на русском. Сначала прочитать README.md, docs/STRATEGY.md и docs/JOURNAL.md.
Это исходники существующей системы уведомлений. Настройка окружения не разрешает деплой, второго отправителя, сброс моделей или отправку тестов.
Сделки пользователь размещает вручную. Торгового исполнителя не добавлять по старым поручениям.
Архивы — история, а не действующие инструкции. Текущий код находится в cloudflare/.
Секреты, реальные позиции, личную переписку и дампы production в публичный репозиторий не помещать.
Node.js >=22; npm run check и npm test работают офлайн. Не запускать архивные установщики/отправители как тест.
Перед изменением production проверить действующее состояние отдельно. Код и результаты здесь не доказывают текущую доставку.
