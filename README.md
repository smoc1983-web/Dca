# DCA800 — стратегия и уведомления

Проект перенесён 26 ноября 2026 года из локальных наработок. Последние найденные локальные облачные модули датированы 10 ноября. Это снимок исходников, а не подтверждение их совпадения с текущим развёртыванием.

Система моделирует циклы START → DCA1…DCA5 → TP/STOP для 19 пар Binance и отправляет сообщения в Telegram через Cloudflare Worker + D1. Реальные ордера не размещает. Пользователь торгует вручную.

## Проверка без запуска отправителя
Требуется Node.js 22 или новее. Зависимостей для офлайн-проверки нет.
```sh
npm run check
npm test
```

`cloudflare/` — основной код. `strategy/markets.json` — исторический снимок параметров 19 моделей. `archive/` — ранние Pine-версии, локальные модули, исследования, не текущая конфигурация запуска. Некоторые архивные скрипты требуют старые пути и свечные кэши.

Секреты Telegram/Cloudflare, D1 с текущими моделями, полная личная переписка и свечные архивы не опубликованы. Пример Wrangler не содержит cron и действующей БД. Публикация на GitHub не включает уведомления и не меняет работающий Worker. GitHub Actions для отправки не используется.
