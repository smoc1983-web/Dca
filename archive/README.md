# Исторические материалы
Эти версии сохраняют наработки, но не являются production-конфигурацией. Приоритет имеют cloudflare/ и docs/STRATEGY.md.
watchlist-research содержит ранний список из 20 пар (в том числе NEAR) и более ранние форматы сообщений. local-pc требует исходной Windows-инфраструктуры. rank-current-original.mjs сохраняет старые импорты, абсолютные зависимости окружения и загрузку данных; не является переносимым запускателем.
Отчёты — исторические результаты и утверждения на дату составления, не свежая проверка. Свечные кэши и частные снимки состояния не публикуются.
