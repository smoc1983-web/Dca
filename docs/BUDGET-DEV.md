# 03 / 03.1 — тестовый бюджет, первый инкремент
Изолированный модуль portfolio-budget.mjs. Не подключён к Worker, реальным сделкам или балансам. Политика equal-slots-v1 — явная тестовая гипотеза, не настройка production. Входы capital, freeCash (предоставленный пул до внутренних резервов, НЕ автоматически balance.available биржи), maxCycles, feeRate обязательны. Бюджет цикла = выделенный капитал / maxCycles, вниз до 8 дробных знаков USDT. START = 25/800 бюджета, следующие 5 сумм ×1.5; номиналы вниз, комиссии вверх до 8 знаков. Номинальный предел 70%, полный резерв с комиссиями должен помещаться в бюджет и общий доступный пул. Учитываются входные комиссии, не комиссии выхода. Реальные фильтры и фактические исполнения не подменяются расчётными.
Резервы пока только ДО исполнений: неизменяемый снимок плана и версии настроек, отказ при недостатке полного резерва, повторном символе или лимите циклов; при смене капитала/лимита прежние планы сохраняются и дефицит виден, новые входы блокируются. Освобождение только неисполненного резерва. Переходы чистые, revision проверяется, данные JSON-совместимы; это ещё не атомарная БД и не защита нескольких независимых писателей без CAS.
Далее: персистентный журнал операций с атомарной проверкой ревизии, подтверждённые исполнения/частичные исполнения, резерв оставшихся DCA, освобождение после закрытия, разделение денежных потоков и PnL, сверка с журналом и фильтрами. Предлагаемые параметры не активированы; плечо отдельно.
