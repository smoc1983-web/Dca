# 03.3 — отдельный учёт пополнения isolated collateral
Первая offline стадия: isolated-collateral.mjs, одно синтетическое наблюдение счёта/площадки с явными открытыми позициями, свободным залогом до резервирования, DCA reserve и явно заданным лимитом защиты. Резерв pending/partial/uncertain вычитается из свободного остатка и лимита; ни одна операция не отправляет деньги. Подтверждённый перевод уменьшает свободный залог и увеличивает залог позиции без изменения quantity/average/lastDca/TP/leverage и без PnL. Повтор opId идемпотентен; конфликт, stale revision, двойное доказательство, чужой счёт и перерасход блокируются. Частичные исполнения сохраняют остаток, uncertain удерживает резерв; отмена только при подтверждении неисполненного остатка. Reduce запрещён. Семь тестов. Лимит protectionCap и порог предупреждения задаются явно, не утверждены для реального режима. Это чистый расчёт на неизменяемом снимке, CAS пока только в памяти; следующий шаг persistent audit/atomic CAS, подтверждённая сверка живого счёта и обновление снимков/исполнений, защита от устаревших данных, расчёт риска и исторический stress с конечным резервом. Реальное наблюдение, fee/funding/закрытие/перевод извне не интегрированы; при расхождении сверка обязательна. Production не изменён.

## Постоянный журнал
isolated-collateral-schema.sql, isolated-collateral-store.mjs: append-only SQLite/D1-shaped audit, key venue/account/revision; единственная начальная запись, повтор идентичной инициализации идемпотентен, сброс запрещён. Replay проверяет непрерывность ревизий и канонические события. Вставка с CAS по MAX(revision) для конкретного счёта, конкуренция не расходует резерв дважды; дубли opId и evidence, partial/uncertain/cancel сохраняются при перезапуске. 8 тестов включая файл SQLite, конкурентные операции, отказ INSERT, неизменяемость, разделение площадок. Только synthetic, без реальных денег. Внешнее обновление наблюдений, actual DCA/fees/funding/close, сверка межжурнальных ревизий, авторизация, живой D1 и risk guard остаются открыты. Следующий шаг — подтверждённая сверка снимка с блокировкой при расхождении.
