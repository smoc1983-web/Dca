# Ограничения и открытые вопросы

- 26.11.2026 выполняется перенос локальных файлов, а не аудит production. Сверка с облачной веткой и текущим Worker отдельно не выполнена.
- Нет текущей D1, секретов, фактических биржевых позиций и полного архива свечей. Нельзя объявлять репозиторий готовой копией работающего сервиса или утверждать, что исторический тест повторён.
- Исторический рейтинг использует подобранные ТФ, текущие на тот момент фильтры биржи и оценку на закрытии свечей. Требуется независимый период проверки, стресс-тест комиссий/исполнения и портфельный тест общего капитала.
- Отсутствие STOP в историческом тесте не означает отсутствие внутрисвечной ликвидации с плечом.
- 19 независимых моделей могут одновременно показывать позиции. Это не проверка доступности денег реального счёта.
- Неопределённый результат Telegram не повторяется автоматически. Необходима процедура проверки uncertain и зависших sending с учётом возможного дубля.
- Исторические якоря моделей влияют на номер DCA. Для совпадения с TradingView нужны одинаковые свечи, начальная дата, настройки, прогрев и исполнения.
- Глубина DCA в текущем движке ограничена константой 5; изменение длины drops требует отдельной проверки логики.
- Архивные скрипты сохраняются для изучения. Они могут обращаться к старым локальным путям, внешним данным и отправлять сообщения при прямом запуске. npm test запускает только новые офлайн-проверки основного кода.

- 28.11.2026 реальный экспорт подтвердил HTTP 403/451 при получении Binance market data; dev диагностика не отменяет ограничения источника. Требуется разрешённый стабильный источник и проверка соответствия OHLC/времени, текущего deployment и восстановления после пропусков. Не подменять свечи/время и не скрывать failed runs.
