# Одна проверка реального бота — read-only
Владелец 28.11.2026 попросил одну проверку действующего бота. Выбран безопасный smoke уже доставленной штатной сводки, без нового сообщения, запуска cron, изменения режима/очереди или торговых сигналов. Не является тестом нового /rating: он пока только offline preview.

1. В панели Cloudflare откройте рабочий Worker dca800-watchlist → Settings → Bindings. Подтвердите DB = dca800-watchlist-state. Не открывать секреты и не публиковать токены.
2. В D1 → указанная база → Console выполните только SELECT:
```sql
SELECT id, datetime(closed/1000,'unixepoch') AS event_utc,
       status, receipt IS NOT NULL AS has_receipt
FROM alerts
WHERE id LIKE 'DAILY:%' AND status='delivered' AND receipt IS NOT NULL
ORDER BY closed DESC LIMIT 1;
```
3. В существующем чате Telegram сверить дату последней штатной сводки с этой записью. Если дата соответствует сегодняшней ожидаемой сводке и сообщение получено, одна проверка доставки пройдена. Если нет строки, дата старая или сообщение отсутствует, не сбрасывать и не повторять автоматически; зафиксировать расхождение. Для точной сверки конкретного сообщения оператор может локально сравнить receipt с ID сообщения, если клиент показывает его. Не передавать содержимое торговых сообщений и секреты в Git.

Время в UTC, расписание штатной сводки 06:00 UTC+4 при DAILY_SUMMARY=on, фактическое время доставки зависит от очереди. Это проверка уже существующей доставки, не новый запрос Telegram и не доказательство доступности в следующий момент. В текущей сессии Browser list_tabs недоступен (требуется исходный контекст подключённого браузера); поиск доступных плагинов Cloudflare/Telegram не дал подходящего инструмента. Результат реального smoke не подтверждён. Пользователь может прислать скрин результата SELECT и соответствующей сводки с закрытыми личными данными. Новых сообщений не отправлялось.
