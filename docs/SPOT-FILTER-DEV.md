# Проверка минимального START — dev
Публичные spot exchangeInfo и ticker/price на data-api.binance.vision, без ключей, без обхода отказов, без ордеров. Статические LIMIT PRICE_FILTER/LOT_SIZE/MIN_NOTIONAL/NOTIONAL; цена округляется вниз, количество вниз, минимальный номинал округляется вверх до целого шага. Проверяются 5/10/15 USDT на 11 активных парах; это номиналы спота, не фьючерсные лимиты или допуск сделки. Минимум зависит от цены, динамические ценовые ограничения, MARKET_LOT_SIZE, account filters, доступность средств и исторические правила не проверяются. При отсутствии данных или HTTP отказе не придумывать значения. Следом отдельный guard входа/DCA по подтверждённому обеспечению; production не менять. 4 новых теста.
